# 根本问题诊断总结

## 🎯 核心发现

通过测试用户提供的具体URL，发现了真正的问题！

```
URL: https://std.samr.gov.cn/gb/search/gbDetailed?id=234D7936AB54E194E06397BE0A0AA0A9&review=true
```

### 测试结果对比

| 尝试方式 | 结果 | Content-Length | 问题 |
|--------|------|----------------|------|
| 无headers | ✓ 成功 | 82377 bytes | 正常 |
| 基础UA "Mozilla/5.0" | ✗ 超时 | - | **太简单被识别** |
| Chrome完整UA | ✓ 成功 | 82486 bytes | 正常 |
| UA+Referer+完整headers | ✓ 成功 | 82427 bytes | 正常 |
| 去掉&review=true | ✓ 成功 | 82427 bytes | **&review=true不是问题** |

### 关键结论

1. **URL本身没问题** ✅
   - `&review=true` 参数是合法的
   - 可以正常获取到采标内容

2. **问题出在headers** ❌
   - 无headers：成功
   - 简单UA：超时（被识别为爬虫）
   - 完整UA + headers：成功

3. **&review=true不是瓶颈** ✅
   - 不带参数也能获取内容
   - 问题是部分请求超时/被阻止

**改之后**：
```python
def build_request_headers(url: str) -> dict[str, str]:
    headers = {
        # 更真实的Chrome User-Agent（包含完整版本号）
        "User-Agent": (
            "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
            "AppleWebKit/537.36 (KHTML, like Gecko) "
            "Chrome/124.0.0.0 Safari/537.36"  # ← 加上.0.0版本号
        ),
        # 加入所有必要的headers，模拟真实浏览器
        "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,image/apng,*/*;q=0.8",
        "Accept-Encoding": "gzip, deflate, br",
        "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
        "Cache-Control": "no-cache",
        "Pragma": "no-cache",
        "Sec-Fetch-Dest": "document",
        "Sec-Fetch-Mode": "navigate",
        "Sec-Fetch-Site": "none",
        "Sec-Fetch-User": "?1",
        "Sec-Ch-Ua": '"Chromium";v="124", "Google Chrome";v="124", ";Not A Brand";v="99"',
        "Sec-Ch-Ua-Mobile": "?0",
        "Sec-Ch-Ua-Platform": '"Windows"',
        "Upgrade-Insecure-Requests": "1",
    }

    host = urlparse(url).netloc.lower()
    if "std.samr.gov.cn" in host or "openstd.samr.gov.cn" in host:
        # 不同的host用不同的Referer
        if "std.samr.gov.cn" in host:
            headers["Referer"] = "https://std.samr.gov.cn/"
        else:
            headers["Referer"] = "https://openstd.samr.gov.cn/"

    return headers
```

    for attempt in range(max_retries):
        try:
            return fetch_url_content(url, timeout), url
        except HTTPError as exc:
            # 对401进行一次重试

## 💡 解决方案

### **方案A：改进现有流程（推荐） ✅**

1. **保持多线程workers=10**（不需要降低）
   
2. **为review端点添加重试+延迟机制**
   ```python
   # fetch.py中修改
   def fetch_review_with_retry(url, max_retries=3):
       for attempt in range(max_retries):
           try:
               # 请求review端点
               result = fetch_with_timeout(url, timeout=10)
               if result.status == 401:
                   if attempt < max_retries - 1:
                       wait = min(2 ** attempt, 10)  # 指数退避: 1s, 2s, 4s
                       time.sleep(wait)
                       continue
               return result
           except Exception:
               pass
   ```

3. **在newGbInfo + review之间加延迟**
   ```python
   # 如果newGbInfo无数据，等待后再访问review
   def extract_caibiao_info(hcno):

       result = extract_from_newgbinfo(hcno)
       if not result:
           time.sleep(0.5)  # 等500ms后再访问review
           result = fetch_review_fallback(hcno)
       return result
   ```

4. **添加review端点智能选择**
   ```python

   # 这样单个任务更快，但提取率可能降低
   ```

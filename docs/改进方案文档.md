## 🛠️ 改进方案 (逐步实施)

### 第1步：添加重试机制到 fetch.py

在fetch.py中添加重试包装函数：

```python
import time
from urllib.request import urlopen, Request
from urllib.error import HTTPError

def fetch_url_with_retry(url: str, max_retries: int = 3, 
                        base_delay: float = 1.0, timeout: int = 10) -> dict:
    """
    发起URL请求，如遇401自动重试
    
    Args:
        url: 请求URL
        max_retries: 最大重试次数
        base_delay: 初始延迟(秒)，之后指数增长
        timeout: 请求超时(秒)
    
    Returns:
        {'status': int, 'content': str or None, 'error': str or None}
    """
    for attempt in range(max_retries):
        try:
            headers = {
                'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)',
                'Referer': 'https://openstd.samr.gov.cn/'
            }
            req = Request(url, headers=headers)
            response = urlopen(req, timeout=timeout)
            content = response.read()
            return {
                'status': response.status,
                'content': content,
                'error': None,
                'attempt': attempt
            }
        
        except HTTPError as e:
            if e.code == 401 and attempt < max_retries - 1:
                # 401 Unauthorized - 等待后重试
                wait_time = base_delay * (2 ** attempt)  # 指数退避
                wait_time = min(wait_time, 10)  # 最高等10秒
                
                # 记录日志（可选）
                print(f"  [retry] 收到401，{wait_time}s后重试 (尝试 {attempt+1}/{max_retries})")
                time.sleep(wait_time)
                continue
            else:
                # 其他HTTP错误或已达最大重试
                return {
                    'status': e.code,
                    'content': None,
                    'error': f'HTTP {e.code}',
                    'attempt': attempt
                }
        
        except Exception as e:
            if attempt < max_retries - 1:
                wait_time = base_delay * (2 ** attempt)
                wait_time = min(wait_time, 10)
                print(f"  [retry] 网络错误: {type(e).__name__}，{wait_time}s后重试")
                time.sleep(wait_time)
                continue
            else:
                return {
                    'status': None,
                    'content': None,
                    'error': str(type(e).__name__),
                    'attempt': attempt
                }
    
    return {
        'status': None,
        'content': None,
        'error': 'Max retries exceeded',
        'attempt': max_retries
    }
```

## ⚠️ 注意事项

1. **阻塞式等待**：重试时 time.sleep() 会阻塞当前线程，不方面其他worker的工作。如果需要更优化的实现，应该用异步或回调。但对于当前规模足够了。

2. **指数退避上限**：设置了最高10秒等待，避免单个重试等太久。

3. **日志输出**：可选添加logging模块记录每次重试，便于调试。

4. **review_retry_delay参数**：
   - 1.0s (默认)：平衡速度和成功率
   - 0.5s：更快但成功率略低
   - 2.0s：更稳定但很慢

## ⚠️ 为什么采标提取率仍为0%

### 流程分析
```
1️⃣ 从 newGbInfo 提取采标
   └─ 结果：大部分无采标信息
   
2️⃣ Fallback 到 review 端点
   └─ 结果：~65% 返回HTTP 401
   └─ 原因：review端点有额外限制

3️⃣ 最终结果
   └─ 采标提取率：0%  😞
```

### 根本原因
- newGbInfo 端点：✅ 正常（0% 401）
- review 端点：❌ 受限（65% 401）
- 问题仅限 review 端点，不是IP层面问题
